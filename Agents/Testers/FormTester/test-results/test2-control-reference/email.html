Pattern-validated

{
  "id": "email_validated",
  "type": "email",
  "label": "Email — Pattern-Validated",
  "order": 6,
  "required": true,
  "validation": {
    "required": true,
    "pattern": "^[^\\s@]+@[^\\s@]+\\.[^\\s@]+$",
    "message": "Enter a valid email address"
  }
}
Confirmed real behavior, not assumed: `type: "email"` is a UI hint only. If you need real email-format enforcement you MUST add `validation.pattern` yourself.
