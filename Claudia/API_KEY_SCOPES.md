# Default API Key Scopes

**Use these scopes when creating a new developer API key.**

```
MCP:APP-STUDIO:READ
MCP:APP-STUDIO:WRITE
MCP:ATLAS-FORMS:READ
MCP:ATLAS-FORMS:WRITE
MCP:WORKFLOW:READ
MCP:WORKFLOW:WRITE
MCP:SERVERS:READ
MCP:SERVERS:WRITE
MCP:CREDENTIALS:READ
MCP:CREDENTIALS:WRITE
MCP:DOCUMENTS:READ
MCP:DOCUMENTS:WRITE
MCP:KNOWLEDGE:READ
MCP:KNOWLEDGE:WRITE
```

## When to Use

- **API key creation:** Always include all 14 scopes above
- **Key name:** `bizfirst-claude-full-dev`
- **Expiry:** 90 days
- **Access level:** Full developer access for building in all studios

## For Agents

Reference this file when:
1. Offering to create an API key
2. Explaining what scopes the key will have
3. Guiding users through API key generation

**Always explicitly list all scopes** — do not say "full access" or "all scopes" without the explicit list.
